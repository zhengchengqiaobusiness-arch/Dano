# 统一记忆部署修复契约

需求方要求：统一部署入口，内部完成权限隔离，沿用现有用户会话目录；新增记忆数据单独存放。

- 普通镜像与现有 Compose / Release Build 是唯一产品部署入口；没有另一套 protected 镜像、命令或运行目录。
- Linux 容器内部启动特权管理进程，HTTP 服务降权，模型工具按用户隔离；不得通过统一入口取消隔离。
- 现有 DANO_RUNTIME_DIR、DANO_SESSIONS_ROOT（及原别名、CLI 优先级）继续决定会话路径。已有 JSONL 及其工作区编码不移动、不重写。
- 首次接管普通部署仅接受原宿主拥有的数据；已分配的工具身份在重启/升级后稳定，丢失映射不重新分配。
- OpenViking 保持记忆正文与索引的唯一主存储；本地独立持久化身份、凭证、投递和恢复状态及必要待投递正文。不得重建向量库。
- 既有部署启动和发布配置必须可用；发布不得递归重置已隔离用户文件的所有权。
- 2026-09-29 需求方明确要求不再进行本机 Podman 验证。仅做静态检查、构建、单元/进程测试和代码审查；不得把未执行的真实容器/浏览器路径标记为通过。
