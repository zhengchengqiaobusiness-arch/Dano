# 活选项

调用方字段的候选必须打 listed 里已经出现过的选项请求，不得把录制当时看到的几条冻成默认。页面上是下拉、枚举、单选时，调用方也必须是选项，不要改成自由文本。

## 写法

- 选项命令先按证据再读，把 id 和 label 写入同一张 `questions[]` 的 `options`。
- 不要把「运行某命令」写成唯一 option，也不要留一个占位 id。
- 不要 `dataSource`。调用方 guide 要的是 `{type:"api"}` 形状；本场方法是把活结果直接放进 `options`。
- listed 某键这次是空数组，只说明这次请求传了空，不是该键永远空。同场另有该键的选项请求，来源是再读后调用方选，不要冻成 `[]`。
- 用户看见 label，接口接收稳定 id。
- 树形结果按接口给出的 children 字段展平后再列给调用方。
- 选项接口和业务接口走同一套 `auth.local.json` / `DANO_AUTH_HEADERS`。401 按鉴权规范停止。

## 失败即停

选项接口失败、空列表、或无法映射到稳定 id：

- 停问调用方
- 不得默默取第一条
- 不得用录制样本冒充实时选项
- 不得把未识别来源写成可执行默认
