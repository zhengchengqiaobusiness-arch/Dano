# 调用方输入

调用方填写的字段写在 `SKILL.md` 参数和 `scripts/client.py` 命令行，不要写成页面怎么点。

## 要问调用方

- 继续办理前必须取得的输入
- 需要调用方填写的字段
- 需要调用方从选项接口返回里选择
- 需要调用方核对即将提交的值

## 不要问

- 答案已能从 listed 已录请求确定（当前账号、部门、权限、系统默认）
- 字段是否存在、如何映射——这些在生成 Skill 时由证据决定
- 只需说明结果，不需要新输入

相关字段放在同一条命令的参数里。每个调用方字段给出当前业务上下文里的非空说明。`required` 只决定调用方能否省略，不等于页面上填过。

需要选项时：命令先打 listed 里的选项请求，再让调用方选。不要把录制样本写成静态选项并宣称已解决。
